# Infinite Scroll Benchmark

Test infinite scrolling with virtualization and scroll position management.

## Steps

1. Navigate to `http://localhost:4244/benchmark/infinite-scroll`.
2. Scroll the feed until at least 60 items are loaded.
3. Turn virtualization off, then on again.
4. Jump to item `100` using the input and "Jump to" button.
5. Scroll to top, then restore the previous scroll position.
6. Load one additional batch using the "Load more" button.
