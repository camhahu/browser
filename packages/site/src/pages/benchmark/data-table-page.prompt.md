# Data Table Benchmark

Test a data table with sorting, filtering, inline editing, and bulk actions.

## Steps

1. Navigate to `http://localhost:4244/benchmark/data-table`.
2. Filter the table to show only Active users in Engineering.
3. Sort the table by "Last Active" (most recent first).
4. Edit the name cell for `Alice Chen` to `Alice Chen Jr` and save the edit with Enter.
5. Select `Bob Martinez`, `Carol Williams`, and `David Kim` (use shift-click to select the range).
6. Delete the selected users and confirm they are removed.
7. Select `Alice Chen Jr` and `Eva Johnson`, then export the selection.
8. Use pagination to go to the next page, then return to page 1.
9. Reset filters so the full table is visible again.
