# Drag & Drop Benchmark

Test a kanban board with draggable cards and undo/redo.

## Steps

1. Navigate to `http://localhost:4244/benchmark/drag-drop`.
2. Move "Research competitor features" from "Backlog" to "To Do".
3. Reorder the "Backlog" column so "Design system audit" appears above "Write API documentation".
4. Move "Implement user auth" down one position using its move control.
5. Undo the last move, then redo it.
6. Move "Project kickoff meeting" from "Done" to "In Progress".
